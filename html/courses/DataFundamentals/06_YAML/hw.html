Homework: YAML Data Format

Exercises

Exercise 1: JSON to YAML Conversion

  1. Take a complex JSON file (minimum 50 lines)
  2. Convert it manually to YAML format
  3. Compare readability and file size
  4. Document the differences you observe

Exercise 2: Configuration Files

  1. Create a YAML configuration for a web application:
    - Database settings
    - Server configuration
    - Feature flags
    - Environment variables
  2. Include comments explaining each section
  3. Use YAML anchors and aliases for repeated values

Exercise 3: YAML Syntax Mastery

  1. Practice different YAML data types:
    - Scalars, sequences, mappings
    - Multi-line strings (literal and folded)
    - Boolean and null values
    - Numbers in different bases
  2. Create nested structures with proper indentation
  3. Test edge cases with special characters

Exercise 4: Validation and Testing

  1. Create intentionally invalid YAML files
  2. Use online validators to check syntax
  3. Fix common YAML parsing errors
  4. Document best practices for avoiding issues

Practical Tasks

Task 1: CI/CD Configuration
- Create a GitHub Actions workflow in YAML
- Include multiple jobs, steps, and conditions
- Use environment variables and secrets

Task 2: Docker Compose
- Write a docker-compose.yml file for a multi-service application
- Include networks, volumes, and dependencies
- Test the configuration

Task 3: Kubernetes Configuration
- Create basic Kubernetes manifests in YAML
- Define pods, services, and deployments
- Apply proper labeling and selectors

Programming Integration

Task 4: Language-Specific Practice
Choose your preferred language and:
- Parse YAML files programmatically
- Generate YAML from data structures
- Handle parsing errors gracefully
- Convert between YAML and other formats

Tools Practice

Learn to use YAML parsers and tools:
- yamllint for syntax checking
- yq for querying YAML data
- Language-specific libraries (PyYAML, js-yaml, etc.)

Submission Requirements

Submit your completed work including:
1. All created YAML files
2. Conversion examples with explanations
3. Error handling examples
4. A reflection document comparing YAML with JSON and XML
