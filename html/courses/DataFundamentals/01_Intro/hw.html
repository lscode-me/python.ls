Homework: Introduction to Data Concepts

Exercises

Exercise 1: Data Types

  1. Identify different types of data in your daily life
  2. Classify them as structured, semi-structured, or unstructured

Exercise 2: Information vs Data

  1. Give examples of raw data and derived information
  2. Explain the transformation process

Exercise 3: File Formats

  1. Find 3 different file formats on your computer
  2. Identify their purpose and structure

Practical Tasks

Task 1: Create a simple data inventory
- List 10 different data sources you encounter
- Categorize them by type and format

Task 2: Data quality assessment
- Choose one data source
- Evaluate its completeness, accuracy, and consistency

Submission

Submit your completed exercises as a markdown file with your observations and conclusions.
