Sample Data Files

All sample data files used throughout the course are available in the files/ subfolder.

Quick start: To create all files locally at once, copy-paste the setup script at the bottom of this page into your terminal.

📁 Setup Options

Option 1: Use files directly from the repository

cd Linux/data/files/
cat users.csv

Option 2: Copy to your working directory

cp -r Linux/data/files/* ~/workspace/linux_course_data/
cd ~/workspace/linux_course_data

Option 3: Run DuckDB examples

cd Linux/data/files/
./duckdb_examples.sh

The duckdb_examples.sh script demonstrates:
- Querying CSV files with SQL
- Joins across multiple files
- Aggregations and GROUP BY
- Window functions (ROW_NUMBER, running totals)
- Exporting to CSV and Parquet formats
- Common analytical queries
