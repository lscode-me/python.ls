Iteration Protocol - Homework

  1. Custom Iterator Classes Create the following iterator classes:

a) RangeIterator - mimics built-in range() - Support start, stop, step - Implement iter and next - Handle negative steps

b) CycleIterator - cycles through items infinitely - Takes any iterable - Repeats forever - Track iteration count

c) BatchIterator - yields items in batches - Takes iterable and batch size - Last batch may be smaller - Support overlapping batches (optional)

Your task: - Implement both iter and next - Handle StopIteration correctly - Test with various inputs - Compare with itertools equivalents

Your goal: - Master iterator protocol - Understand iter vs next - Practice state management in iterators

  1. Generator Functions Implement the following generators:

a) fibonacci(n) - first n Fibonacci numbers b) primes(max_num) - all primes up to max_num c) permutations(items, r) - all r-length permutations d) sliding_window(iterable, size) - sliding window view e) flatten(nested) - flatten nested structures

Your task: - Use yield for lazy evaluation - Handle edge cases (empty input, size=1, etc.) - Make memory efficient (no lists) - Test with large inputs

Example: for window in sliding_window([1,2,3,4,5], 3): print(window) # [1,2,3], [2,3,4], [3,4,5]

Your goal: - Master yield statement - Understand lazy evaluation - Practice generator patterns

  1. Generator Expressions and Pipelines Create data processing pipelines using generators:

Given a log file with entries like: 2023-11-26 10:15:23 ERROR Connection failed 2023-11-26 10:15:24 INFO Request processed

Tasks: a) Parse log entries (generator) b) Filter by log level (generator) c) Extract timestamps (generator) d) Group by hour (generator) e) Generate statistics (generator)

Your task: - Use generator expressions where possible - Chain generators into pipeline - Keep each stage simple and focused - Compare memory usage with list-based approach

Your goal: - Master generator expressions - Learn pipeline architecture - Understand lazy evaluation benefits

  1. Advanced Generator Methods Explore send(), throw(), and close():

a) Coroutine: running average calculator - Use send() to add values - Returns current average

b) State machine generator - Multiple states with transitions - Use send() to trigger transitions

c) Error-handling generator - Use throw() to inject errors - Generator catches and handles them

Your task: - Implement bidirectional communication - Handle exceptions in generators - Demonstrate proper cleanup with close() - Show practical use cases

Your goal: - Master generator methods - Understand coroutines - Practice advanced iteration patterns

  1. yield from and Generator Delegation Implement using yield from:

a) Tree traversal (depth-first and breadth-first) b) Recursive directory walker c) Nested data structure flattener d) Chain multiple data sources e) Recursive parser for nested expressions

Your task: - Use yield from for delegation - Handle recursive structures - Compare with manual iteration - Demonstrate code simplification

Example: def traverse_tree(node): yield node.value for child in node.children: yield from traverse_tree(child)

Your goal: - Master yield from - Simplify recursive generators - Understand generator delegation

  1. itertools Mastery Solve problems using itertools module:

a) Generate all password combinations (4-8 chars, letters+digits) b) Find all triplets in list that sum to target c) Create round-robin scheduler from tasks d) Implement pagination with islice e) Group and aggregate data with groupby

  1. Custom Iterable Classes Create iterable classes for:

  1. Infinite Sequences Create infinite generators:

a) Collatz sequence generator b) Random number stream with seed c) Infinite repeat with delays d) Streaming data simulator e) Infinite geometric series
