Homework: Checksums and Data Integrity

Exercises

Exercise 1: Hash Algorithm Comparison

  1. Calculate and compare different hash functions: - MD5, SHA-1 (deprecated but still encountered) - SHA-256, SHA-512 (current standards) - Blake2, SHA-3 (modern alternatives) - CRC32 (fast but weak)
  2. Test hash calculation for: - Small text files - Large binary files - Identical content in different formats - Files with single bit differences
  3. Document performance characteristics of each algorithm
  4. Understand security implications and appropriate use cases

Exercise 2: File Integrity Verification

  1. Create integrity verification workflows: - Generate checksums for file collections - Verify integrity after file transfers - Detect corruption in stored files - Automate integrity checking in scripts
  2. Practice with different checksum file formats: - md5sum, sha256sum output formats - Custom checksum manifests - Integration with version control systems
  3. Handle edge cases: - Missing files - Permission issues - Path differences across systems

Exercise 3: Data Transmission Verification

  1. Implement end-to-end data integrity: - Calculate checksums before transmission - Verify checksums after reception - Handle checksum mismatches gracefully - Implement retry mechanisms for failed transfers
  2. Practice with different protocols: - HTTP with ETag headers - FTP with hash verification - Email attachments with checksums - Cloud storage integrity checking

Exercise 4: Digital Signatures and Authentication

  1. Learn about cryptographic signatures: - Public/private key concepts - Message Authentication Codes (HMAC) - Digital signature verification - Certificate chain validation
  2. Practical signature implementation: - Sign files with GPG/PGP - Verify software package signatures - Create and verify JWT tokens - Implement HMAC for API authentication
