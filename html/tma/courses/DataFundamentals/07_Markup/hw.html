Module 7 - Homework

Homework: Markup Languages

Exercises

Exercise 1: HTML Document Creation

  1. Create a semantic HTML5 document with: - Proper DOCTYPE declaration - Header with navigation menu - Main content area with articles - Sidebar with related links - Footer with contact information
  2. Use semantic HTML5 elements (header, nav, main, article, aside, footer)
  3. Include proper meta tags for SEO
  4. Validate HTML using W3C validator

Exercise 2: XML Data Representation

  1. Design an XML schema for a library catalog: - Books with authors, ISBN, categories - Multiple authors per book - Publication information - Availability status
  2. Create a sample XML file with at least 10 books
  3. Write an XSD schema to validate the structure
  4. Test validation with online tools

Exercise 3: Markdown Documentation

  1. Write comprehensive documentation for a project: - README with installation instructions - API documentation with code examples - User guide with screenshots (placeholder links) - Changelog with version history
  2. Use advanced Markdown features: - Tables, code blocks, links, images - Task lists, footnotes, emoji - Math expressions (if supported)

Exercise 4: Format Conversion

  1. Convert the same content between formats: - HTML → XML → Markdown - Preserve structure and meaning - Document what's lost/gained in each conversion
  2. Use automated tools and manual methods
  3. Compare pros and cons of each approach

Practical Tasks

Task 1: Website Structure - Build a multi-page website using only HTML - Create consistent navigation across pages - Include forms with proper input validation - Test accessibility with screen readers

Task 2: Data Exchange Format - Design XML for data exchange between systems - Include proper namespace declarations - Create comprehensive documentation - Test with XML parsing libraries

Task 3: Technical Writing - Write technical documentation in Markdown - Include diagrams using mermaid syntax - Create a style guide for consistent formatting - Generate HTML/PDF from Markdown source

Advanced Challenges

Challenge 1: Custom XML Processing - Write XSLT transformations for XML data - Create custom XML to HTML conversion - Implement XML querying with XPath

Challenge 2: Markdown Extensions - Research and use extended Markdown syntax - Create custom renderer for special needs - Compare different Markdown flavors (GitHub, CommonMark, etc.)

Comparison Study

Create a detailed comparison report: - When to use HTML vs XML vs Markdown - Performance considerations - Tool ecosystem for each format - Industry adoption patterns - Future trends and developments

Submission Requirements

Submit a portfolio containing: 1. All created markup files 2. Validation reports and screenshots 3. Comparison analysis document 4. Reflection on markup language strengths/weaknesses
