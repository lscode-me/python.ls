Bonus 1: Streaming Statistics Calculator

Calculate running statistics without storing all data. - Script (streaming_stats.py): ```python #!/usr/bin/env python3 import sys import json import math

count = 0 sum_val = 0 sum_sq = 0 min_val = float('inf') max_val = float('-inf')

for line in sys.stdin: try: num = float(line.strip()) count += 1 sum_val += num sum_sq += num ** 2 min_val = min(min_val, num) max_val = max(max_val, num) except ValueError: continue

if count > 0: mean = sum_val / count variance = (sum_sq / count) - (mean ** 2) stddev = math.sqrt(variance) if variance > 0 else 0

  stats = {
      "count": count,
      "sum": sum_val,
      "mean": mean,
      "stddev": stddev,
      "min": min_val,
      "max": max_val
  }
  print(json.dumps(stats, indent=2))

`` - Usage:seq 1 1000 | python3 streaming_stats.py` - Advantage: O(1) memory, single pass
