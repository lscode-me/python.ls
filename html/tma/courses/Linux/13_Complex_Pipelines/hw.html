Assignment 4: Staging with Temporary Files

Create pipeline with explicit staging areas. - Script (staged_pipeline.sh): ```bash #!/bin/bash set -euo pipefail

# Setup staging areas STAGE1=$(mktemp -d) STAGE2=$(mktemp -d) STAGE3=$(mktemp -d) FINAL="output"

mkdir -p "$FINAL"

# Cleanup on exit trap 'rm -rf "$STAGE1" "$STAGE2" "$STAGE3"' EXIT

echo "Stage 1: Extract → $STAGE1" curl -s "https://jsonplaceholder.typicode.com/users" > "$STAGE1/users.json" ls -lh "$STAGE1"

echo "" echo "Stage 2: Transform → $STAGE2" jq -c '.[]' "$STAGE1/users.json" > "$STAGE2/users.jsonl" jq -c '. | {id, name, email, company: .company.name}' "$STAGE2/users.jsonl" > "$STAGE2/users_clean.jsonl" ls -lh "$STAGE2"

echo "" echo "Stage 3: Enrich → $STAGE3" cat "$STAGE2/users_clean.jsonl" | \ python3 -c " import sys, json for line in sys.stdin: user = json.loads(line) user['name_length'] = len(user['name']) user['email_domain'] = user['email'].split('@')[1] print(json.dumps(user)) " > "$STAGE3/users_enriched.jsonl" ls -lh "$STAGE3"

echo "" echo "Stage 4: Load → $FINAL" jq -r '[.id, .name, .email_domain, .company] | @csv' "$STAGE3/users_enriched.jsonl" > "$FINAL/users_final.csv" ls -lh "$FINAL"

echo "" echo "Pipeline complete! Output in $FINAL/" ```

Assignment 9: Error Recovery and Retry

Implement robust error handling with retries. - Script (retry_pipeline.sh): ```bash #!/bin/bash set -uo pipefail # Note: no -e, we handle errors manually

MAX_RETRIES=3 RETRY_DELAY=2

# Retry function retry() { local max_attempts=$MAX_RETRIES local delay=$RETRY_DELAY local attempt=1

  while [ $attempt -le $max_attempts ]; do
      echo "Attempt $attempt/$max_attempts: $*"

      if "$@"; then
          return 0
      fi

      local exit_code=$?

      if [ $attempt -lt $max_attempts ]; then
          echo "Failed with exit code $exit_code, retrying in ${delay}s..."
          sleep $delay
          delay=$((delay * 2))  # Exponential backoff
      fi

      attempt=$((attempt + 1))
  done

  echo "All attempts failed"
  return 1

}

# Fetch with retry fetch_data() { local url=$1 local output=$2 retry curl -f -s "$url" -o "$output" }

# Pipeline echo "Fetching data with automatic retry..."

if fetch_data "https://jsonplaceholder.typicode.com/users" "users.json"; then echo "✓ Data fetched successfully" jq -c '.[]' users.json > users.jsonl echo "✓ Processing complete" else echo "✗ Failed to fetch data after $MAX_RETRIES attempts" exit 1 fi ```
