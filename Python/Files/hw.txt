Homework Assignments - File Handling
-------------------------------------

1. Basic File Operations
   Create a file manager script with the following functions:
   
   a) read_file(filename) - read and return file contents
   b) write_file(filename, content) - write content to file
   c) append_to_file(filename, content) - append content
   d) count_lines(filename) - return number of lines
   e) count_words(filename) - return number of words
   f) find_in_file(filename, search_term) - return line numbers
   
   Your task:
   - Implement all functions with proper error handling
   - Use context managers for all file operations
   - Handle different encodings (UTF-8, ASCII)
   - Test with various file types and sizes
   
   Your goal:
   - Master basic file I/O operations
   - Understand file modes and encodings
   - Practice error handling with files

2. Log File Analyzer
   Create a log file analyzer that processes web server logs:
   
   Log format example:
       192.168.1.1 - - [26/Nov/2025:10:15:23] "GET /index.html HTTP/1.1" 200 2326
   
   Functions to implement:
   a) parse_log_entry(line) - extract IP, timestamp, request, status, size
   b) analyze_log(filename) - return statistics:
      - Total requests
      - Unique IPs
      - Most common endpoints
      - Status code distribution
      - Total bandwidth
   c) filter_by_status(filename, status_code)
   d) find_errors(filename) - return 4xx and 5xx entries
   
   Your task:
   - Read large log files efficiently (line by line)
   - Parse complex log format
   - Generate comprehensive statistics
   - Export results to JSON and CSV
   
   Your goal:
   - Practice reading large files efficiently
   - Learn text parsing and pattern matching
   - Understand data aggregation from files

   Example operations:

   - Sort by age descending
   - Add "bonus" column (10% of salary)
   - Calculate average salary by department
   
   Your task:
   - Use csv module for reading/writing
   - Implement flexible filtering system
   - Handle missing/invalid data
   - Support large CSV files
   
   Your goal:
   - Master CSV file operations
   - Practice data transformation
   - Learn data validation and cleaning

   Your task:

   Your goal:
   - Master JSON file operations

   d) organize_by_type(path) - organize files by extension
   e) clean_empty_dirs(path) - remove empty directories
   f) generate_tree(path) - create visual tree structure
   
   Your task:
   - Use pathlib for path operations
   - Implement recursive directory traversal
   - Calculate file hashes for duplicate detection
   - Create tree visualization (like Unix `tree` command)
   - Handle symbolic links and permissions errors
   
   Your goal:
   - Master directory operations
   - Learn recursive file system traversal

6. Binary File Processor
   Work with binary files and formats:
   
   Tasks:
   a) Image file header reader (PNG, JPEG, GIF)
   b) File type detector by magic numbers
   c) Binary file splitter/merger
   d) Simple hex viewer
   e) Binary file comparison tool
   
   Your task:
   - Read and interpret binary data
   - Understand file format structures
   - Work with bytes and bytearray
   - Implement chunked reading for large files
   
   Example formats:
   - PNG: starts with 89 50 4E 47

   Your goal:
   - Master binary file operations
