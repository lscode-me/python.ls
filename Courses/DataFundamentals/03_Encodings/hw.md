# Homework: Character Encodings

## Exercises

### Exercise 1: Encoding Exploration
1. Encode your name in ASCII (decimal values)
2. Find characters that can't be represented in ASCII
3. Compare the byte size of text in UTF-8 vs UTF-16

### Exercise 2: Unicode Investigation
1. Find Unicode codepoints for: emoji, accented characters, symbols
2. Explain why Unicode was necessary
3. Research UTF-8, UTF-16, UTF-32 differences

### Exercise 3: Encoding Problems
1. Create a text file with international characters
2. Try opening it with wrong encoding settings
3. Document the corruption patterns you observe

## Practical Tasks

**Task 1:** Encoding detection
- Download text files in different languages
- Use tools to identify their encodings
- Convert between encodings

**Task 2:** Web encoding
- Examine HTTP headers for character encoding
- Test how browsers handle encoding mismatches

## Programming Challenge
Write a script to detect and convert text file encodings.
