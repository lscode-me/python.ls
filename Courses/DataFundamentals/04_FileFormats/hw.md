# Homework: File Formats

## Exercises

### Exercise 1: Format Investigation
1. Collect 10 different file types from your computer
2. Research their magic numbers/signatures
3. Identify text vs binary formats

### Exercise 2: MIME Types
1. List MIME types for common file formats
2. Test how web browsers handle different MIME types
3. Create a mapping of extensions to MIME types

### Exercise 3: Format Conversion
1. Convert an image between different formats (PNG, JPEG, GIF)
2. Compare file sizes and quality
3. Document when to use each format

## Practical Tasks

**Task 1:** File signature analysis
- Use a hex editor to examine file headers
- Create a "magic number" reference for 5 formats

**Task 2:** Cross-platform compatibility
- Test file sharing between different operating systems
- Document any compatibility issues

## Research Project
Choose an uncommon file format and create a detailed analysis report.
