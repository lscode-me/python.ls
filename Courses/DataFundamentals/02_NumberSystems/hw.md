# Homework: Number Systems and Data Representation

## Exercises

### Exercise 1: Binary Conversion
1. Convert these decimal numbers to binary: 42, 128, 255
2. Convert these binary numbers to decimal: 1010, 1111, 10000000

### Exercise 2: Hexadecimal Practice
1. Convert RGB color values to hex: (255,0,0), (128,128,128), (0,255,255)
2. Explain why hex is used in computing

### Exercise 3: Endianness
1. Research big-endian vs little-endian
2. Find out which your computer uses
3. Give examples where this matters

## Practical Tasks

**Task 1:** File analysis
- Use a hex editor to examine a simple text file
- Identify the byte patterns for different characters

**Task 2:** Data size calculations
- Calculate storage requirements for different data types
- Compare efficiency of different representations

## Programming Exercise
Write a simple program to convert between number systems (any language).
