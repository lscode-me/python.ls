# Homework: JSON Data Format

## Exercises

### Exercise 1: JSON Structure
1. Create a JSON file representing your personal information
2. Include nested objects and arrays
3. Validate the JSON syntax

### Exercise 2: Data Conversion
1. Convert a CSV file to JSON format
2. Transform XML data to JSON
3. Compare the file sizes and readability

### Exercise 3: jq Practice
1. Install jq command-line tool
2. Practice filtering and transforming JSON data
3. Create complex queries with jq

## Practical Tasks

**Task 1:** API Integration
- Find a public API that returns JSON
- Parse and extract specific data fields
- Handle errors and edge cases

**Task 2:** JSON Schema
- Create a JSON schema for a data structure
- Validate JSON files against the schema

## Programming Exercise
Write a script to merge multiple JSON files into one.
