# Additional Resources: JSON

## Essential Reading
- [JSON.org](https://www.json.org/json-en.html) - Official JSON introduction
- [MDN JSON Guide](https://developer.mozilla.org/en-US/docs/Learn/JavaScript/Objects/JSON) - Mozilla developer docs

## Tools
- [JSONLint](https://jsonlint.com/) - JSON validator
- [jq Manual](https://stedolan.github.io/jq/manual/) - Command-line JSON processor
- [JSON Formatter](https://jsonformatter.org/) - Online formatting tool

## API Resources
- [JSONPlaceholder](https://jsonplaceholder.typicode.com/) - Fake REST API for testing
- [Public APIs](https://github.com/public-apis/public-apis) - List of free APIs
- [REST API Tutorial](https://restfulapi.net/) - Best practices

## Schema Validation
- [JSON Schema](https://json-schema.org/) - Schema specification
- [AJV](https://ajv.js.org/) - JavaScript validator
- [Online Schema Validator](https://www.jsonschemavalidator.net/) - Test tool

## Programming Libraries
- [Python json module](https://docs.python.org/3/library/json.html) - Built-in support
- [Node.js JSON methods](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/JSON) - Native support
