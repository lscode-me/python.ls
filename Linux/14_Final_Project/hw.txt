# Final Project: Complete ETL Pipeline

See lecture.md for full project requirements and guidelines.

Build a production-ready ETL pipeline processing 5GB+ data with:
- Extract: API/file ingestion
- Transform: Cleaning, filtering, aggregation
- Load: Reports and summaries
- Orchestration: Makefile
- Performance: Parallelism, streaming
- Quality: Error handling, logging, checkpoints

Deliverables:
1. Source code (scripts, Makefile)
2. Documentation (README, ARCHITECTURE)
3. Sample output (reports, logs)

Evaluation:
- Functionality: 40%
- Performance: 20%
- Code Quality: 20%
- Documentation: 20%
